# FitFlow Redesign

## Project Overview

FitFlow is an AI-powered fitness application redesign
developed as part of IT3060 – Human Computer Interaction.

The redesign focuses on improving user engagement through
personalized workouts, social community features and
improved nutrition tracking.

## Main Features

- AI-powered personalized workout plans
- Workout tracking
- Nutrition tracking
- Food image analysis
- Social sharing
- Progress analytics
- Real-time notifications
